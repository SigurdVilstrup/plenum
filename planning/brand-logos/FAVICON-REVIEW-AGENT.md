# Favicon logo critique agent

Use this rubric when reviewing brand marks for Plenum (agent-era Mac git client / lane board). Audience: developers + corporate buyers. Marks must work primarily as **16×16 / 32×32 favicons** and Dock icons.

## Style north star (prefer these over ornate Logobook samples)

- Cursor, Palantir, Anduril, xAI, GitKraken, GitHub, ClickUp
- User reference sheets: bold geometric SaaS marks, consistent stroke, negative space, high silhouette contrast
- First pass: **black & white only** (no color dependency)

## Hard fail criteria (kill or redo)

1. **Dies at 16px** — detail thinner than ~1/8 of the mark width; multi-hairline meshes; fine grids; tiny dots that merge
2. **Color-dependent** — meaning requires hue; B&W silhouette collapses
3. **Letterform accident** — reads as a random letter (H, M, W, E) without intending a monogram
4. **Generic UI chrome** — hamburger, plain equals, loading spinner, robot/ghost mascot
5. **Busy silhouette** — outer contour has too many notches; blur at favicon
6. **Wrong register** — cute, bubbly, gradient-first, or defense-cosplay without product meaning

## Pass / score (1–5 each)

| Axis | 5 means |
|---|---|
| Favicon legibility | Instant blob recognition at 16px |
| Silhouette | Strong outer shape even if internals blur |
| Stroke/mass | One weight language; fill or thick stroke |
| Metaphor fit | Still evokes the name’s meaning after shrink |
| Dev-tool register | Belongs next to Cursor/GitHub in a tab bar |
| B&W integrity | Works as solid black on white AND white on black |

**Overall:** Keep (iterate) / Reshape (new geometry) / Kill

## Per-mark output format

```
### {Name}
- Verdict: Keep | Reshape | Kill
- Favicon (16px): {1–5} — {one sentence}
- Silhouette: {1–5}
- Metaphor: {1–5}
- Register: {1–5}
- Critical issues: …
- If Keep: what to tighten
- If Reshape/Kill: replacement geometry in one line (sheet-style)
```
