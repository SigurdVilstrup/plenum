Early-stage beta. Free while it's open. Expect rough edges and frequent updates.

  • Free in the open beta

    Download it and use it. It costs nothing while the beta is open.

  • A real overview

    Every lane in one view: how far behind main it is, what's uncommitted, and who wrote the last commit. You, an agent, or both.

  • Run several lanes at once

    Each lane is its own worktree with its own ports. Start, stop and test it from the board.

  • Built for busy team repos

    Main stays protected and untouched. Every lane is measured against the team's branch, so you see drift before it hurts.

  • More than one repo

    Every repo gets its own tab, with its own lanes.

  • Agents get lanes, not your git

    A CLI and a local MCP server let Claude Code, Cursor and Codex create, start and test lanes. Commits, pushes and merges stay with you.
