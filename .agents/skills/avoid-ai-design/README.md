# avoid-ai-design

Vendored [agentskills.io](https://agentskills.io) skill that audits AI-generated frontend for generic design patterns (“AI slop”) and rewrites toward an intentional direction.

- Entry point: [`SKILL.md`](SKILL.md)
- Tell catalog: [`references/ai-tells-catalog.md`](references/ai-tells-catalog.md)
- Optional scanner: `node scripts/detect.mjs <path>` (Node 18+)

Upstream: [funboy322/avoid-ai-design](https://github.com/funboy322/avoid-ai-design) (MIT). Demo pages are omitted here to keep this repo lean; use the upstream repo if you want the full before/after set.
